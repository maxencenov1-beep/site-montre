# Catalogue Montre

---

## Description du projet 

**Catalogue Montre** est un site vitrine dédié à la présentation de montres. Il permet aux visiteurs de découvrir une sélection de montres classées par marque, catégorie et type de mouvement, sans fonctionnalité de ventre en ligne.

---

## Fonctionnalité principales

* Affichage d'un catalogue de montres avec photo,nom,référence et description détaillée
* Filtrage par marque (rolex,Seiko...), Catégorie (Luxe,Sport...) et **type de mouvement** (Quartz, automatique...).
* Fiche détaillé pour chaque montre : matériaux du boîtier et du bracelet, étanchéité et prix indicatif

## Aspect technique 

Le site s'appuie sur une base de données MySQL structurée autour de 4 tables reliées entre elles : 
* marques
* catégories
* mouvements
* montres

Cette structure relationnelle permet d'organiser facilement le catalogue et d'ajouter de nouvelles montres,marques ou catégories sans dupliquer l'information.

## Public visé

Amateurs et passionnés d'horlogerie cherchant à explorer et comparer différents modèles de montres dans un but purement informatif et esthétique.
